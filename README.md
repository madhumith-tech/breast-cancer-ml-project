# Breast Cancer Classification using Machine Learning

## Project Overview

This project uses machine learning to classify breast cancer cases as Benign or Malignant using diagnostic measurements.

## Dataset

The dataset contains different measurements related to breast cancer cells.

Target variable:

- B - Benign
- M - Malignant

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib

## Machine Learning Models

The following models were compared:

- Logistic Regression
- Support Vector Machine
- Random Forest
- Gradient Boosting

## Project Workflow

1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Preprocessing
5. Feature Scaling
6. Train-Test Split
7. Model Building
8. Model Comparison
9. Model Evaluation
10. Cross Validation
11. Final Model Saving

## Final Model

SVM was selected as the final model based on the evaluation results.

The model achieved approximately 97% accuracy on the test dataset.
